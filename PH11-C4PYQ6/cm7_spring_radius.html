THE SPRING SETS ITS RADIUS

Stretching moves the mass further out, which demands more pull, which stretches it further.
SET THE SPIN, THEN RELEASE
THE RADIUS IS L PLUS x

The trap is using the extension as the radius. The mass actually circles at r = L + x, so the balance is kx = mω²(L + x), not kmω²x.

That feedback is why the stretch runs away: spinning twice as fast does not double the extension, it quintuples it. Writing the equation at both speeds and dividing eliminates k, m and ω together, leaving the natural length alone.

🎯 Exam link: kx = mω²(L+x) at x = 1, and k(5) = m(2ω)²(L+5). Dividing: 5(L+1) = 4(L+5), so L = 15 cm.
